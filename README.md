# AM PRODUCTION — Live & Concert Production Experience

> **Creating Experiences. Producing Memories.**  
> Official website and digital experience for **AM PRODUCTION** (`@am_production26`), South India's premier live entertainment, concert, and nightlife production company.

---

## 🌟 Overview

AM PRODUCTION engineers large-scale live entertainment, festival stages, and club takeovers across premier venues including **Lord of the Drinks Chennai**, **Hard Rock Cafe Chennai**, **Secret Story**, and **Living Room**.

This repository contains the complete frontend web application featuring:
- **Cinematic Dark-First Visual Architecture**: Crafted with the brand's signature tricolor palette (Cream `#efe6d5`, Sage `#9dbeb7`, and Vermilion `#e73213`).
- **Real Stage & Event Media**: Zero AI/stock photography; authentic downloaded footage and reels from live Chennai gigs.
- **Playable Instagram Story Highlights Tray**: Real-time story progress bars, video playback with sound toggle, and previous/next slide navigation.
- **Playable Event Aftermovies**: Embedded native video player for each event showcase.
- **Interactive Multi-Step Booking & Quote Engine**: Comprehensive enquiry funnel for concerts, festivals, campus events, and private shows.
- **Dedicated Venue Partners Showcase**: Featuring resident nightlife venues with capacity, vibe, and production highlights.
- **Artist Roster & Talent Profiles**: Featuring touring and resident performers including DJ Meet, DJ Rihya, and more.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS with custom glassmorphism, radial lighting gradients, and typography
- **Icons**: Lucide React + Custom SVG branding
- **Media**: Local MP4 video streams & optimized thumbnails

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/adityakajala1/am-production.git
cd am-production
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```
